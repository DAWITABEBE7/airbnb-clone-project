# Airbnb Clone Project

## Project Overview
This project is a full-stack web application that replicates the core features and functionality of Airbnb.

## Project Goals
- To build a scalable, production-ready web application.
- To implement key features such as user authentication, property listing, searching, and booking.
- To gain hands-on experience with a modern tech stack.

## Tech Stack
- Frontend: React.js with Next.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: NextAuth.js
## UI Component Patterns

### Planned UI Components

#### 1. Navbar
- Purpose: Main navigation component for the application
- Features:
  - Logo/branding
  - Search functionality
  - User authentication links (Login/Signup)
  - User menu (when logged in)
  - Responsive design with mobile hamburger menu

#### 2. Property Card
- Purpose: Display individual property listings
- Features:
  - Property image carousel
  - Property title and location
  - Price per night
  - Rating and review count
  - Favorite/heart icon
  - Property type and amenities highlights

#### 3. Footer
- Purpose: Site-wide footer with important links and information
- Features:
  - Company information
  - Quick links (About, Careers, Press)
  - Host resources
  - Support links
  - Social media links
  - Copyright information
